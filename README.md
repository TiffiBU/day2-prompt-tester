# Day 2: Prompt A/B Tester

A small Python project for comparing different prompt versions and saving the results to CSV for review.

## Why I built it

I wanted hands-on experience of testing how changes in prompt wording can affect AI outputs, rather than relying on intuition alone.

## What it does

- Runs alternative prompt versions
- Captures the generated outputs
- Saves results in a structured CSV format
- Makes it easier to compare outputs side by side

## What I learned

This project helped me think more systematically about prompt design, evaluation and iteration: changing one element, reviewing the result and using evidence to decide what works better.

## Why it matters to my work

My background is in learning design, capability development and evaluation. I am building practical AI skills so I can understand emerging tools from the inside and make informed decisions about how they can support learning and users.
